Estudo de caso

Roda de reação de fluido magnético MHD

Dissertação de M.Sc. no ITA: desenvolvimento de uma roda de reação de fluido magnético magnetohidrodinâmica (MHD) para controle de atitude de CubeSat.

Dissertação de M.Sc. no ITA · em andamento · 2025–2027

  • CAD
  • Cálculos
  • Teste
  • Manufatura aditiva

Contexto

Pesquisa de mestrado no Instituto Tecnológico de Aeronáutica (ITA), programa EAM-1 — Projeto Aeronáutico, Estruturas e Sistemas Aeroespaciais. Orientador: Prof. Tiago de Paula. Conclusão prevista para julho de 2027.

Requisitos

  • Função de roda de reação usando um fluido magnético sob atuação MHD, dimensionada para controle de atitude de CubeSat.

Abordagem

Trabalho de dissertação em andamento sobre modelagem e desenvolvimento de protótipo de uma roda de reação de fluido magnético. Detalhe técnico público será acrescentado conforme os resultados forem liberados para divulgação.

Resultados

Pesquisa em andamento (conclusão prevista para julho de 2027). Figuras de desempenho medidas ainda não são publicadas aqui.

Ferramentas

  • Creo / CAD
  • MATLAB
  • Python
  • Instrumentação de laboratório

Confidencialidade

Nenhum dado, desenho ou conjunto de dados confidencial da Visiona ou da Thales Alenia Space é publicado nesta página. O TVAC do SATVHR ainda não foi realizado e não é reivindicado aqui.
